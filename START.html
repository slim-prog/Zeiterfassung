⏰ Zeiterfassung - Schnellstart

🚀 Option 1: Lokale Nutzung (Einfachste)

Öffne einfach diese Dateien im Browser:

  1. Gehe zum Ordner: Zeiterfassung
  2. Klicke mit Doppelklick auf index.html
  3. Die App öffnet sich im Browser!
⚠️ Hinweis: Wenn du Probleme mit localStorage hast, nutze Option 2 statt Option 1.

☁️ Option 2: Online-Server (Empfohlen)

Für zuverlässige Datenfreigabe mehrerer Benutzer auf dem Schul-Netzwerk:

Mit Replit (Kostenlos):

  1. Gehe zu replit.com
  2. Erstelle einen neuen "HTML, CSS, JS" Projekt
  3. Kopiere die Inhalte aus:
    • index.html → index.html
    • dashboard.html → dashboard.html
    • styles.css → styles.css
    • auth.js → auth.js
    • app.js → app.js
  4. Klicke auf "Run" und teile den Link mit schülern!

Mit Python HTTP-Server (Falls Python installiert ist):

  1. Öffne Terminal/CMD im Ordner Zeiterfassung
  2. Führe aus: python -m http.server 8000
  3. Öffne: http://localhost:8000
  4. Fertig!

🧪 Test-Anleitung

Schritt 1: Konto erstellen

  1. Klicke auf "Registrieren"
  2. Username: testuser1
  3. Passwort: password123
  4. Bestätige Passwort: password123
  5. Klicke "Konto erstellen"

Schritt 2: Anmelden

  1. Zurück zu "Anmelden"
  2. Username: testuser1
  3. Passwort: password123
  4. Klicke "Anmelden"
  5. ✅ Du solltest zum Dashboard weitergeleitet werden

Schritt 3: Dashboard testen

  • ✅ "Status Heute" sollte "Anwesend" zeigen (grün)
  • ✅ Der heutige Tag im Kalender sollte grün sein
  • ✅ Statistiken sollten aktualisiert sein
  • ✅ Anmeldungszeit sollte in Tabelle angezeigt werden

Schritt 4: Auto-Absent Test

  1. Wenn es nach 12:00 Uhr ist:
  2. Erstelle ein neues Konto (z.B. testuser2)
  3. Melde dich NICHT an über die normale Anmeldung
  4. Öffne die Browser-Konsole (F12 → Console)
  5. Gebe ein: localStorage.getItem('attendance')
  6. ✅ Du solltest sehen, dass testuser2 auf "absent" gesetzt ist

Schritt 5: Backup testen

  1. Melde dich an
  2. Scrole zu "Datensicherung"
  3. Klicke "Daten exportieren (JSON)"
  4. ✅ Ein JSON-File sollte heruntergeladen werden
  5. Klicke "Daten importieren (JSON)" und wähle die Datei
  6. ✅ Daten sollten wiederhergestellt werden

⚙️ Browser-Konsole für Debugging

Wenn etwas nicht funktioniert, öffne die Konsole (F12) und überprüfe:

// Alle Benutzer anzeigen
console.log(JSON.parse(localStorage.getItem('users')))

// Alle Anwesenheitsdaten anzeigen
console.log(JSON.parse(localStorage.getItem('attendance')))

// Aktuellen Benutzer anzeigen
console.log(JSON.parse(localStorage.getItem('currentUser')))

// localStorage löschen (wenn etwas kaputt ist)
localStorage.clear()

💡 Tipps & Tricks

  • Mehrere Tests: Öffne mehrere Browser-Tabs mit unterschiedlichen Nutzern
  • Daten durcheinander?: Drücke F12 → Console und gebe localStorage.clear() ein
  • Sichere deine Daten: Exportiere regelmäßig JSON-Backups
  • Zeitzonen: Die App nutzt die Systemzeit deines Computers
